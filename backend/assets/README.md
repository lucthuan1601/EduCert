# Font PDF

`NotoSans-Regular.ttf` hỗ trợ tiếng Việt, lấy từ dự án Noto:

- Font: https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf
- Giấy phép: `OFL.txt`, SIL Open Font License 1.1, giữ kèm font khi phân phối.

Backend đọc font cục bộ, không tải font hoặc gửi dữ liệu chứng chỉ ra mạng khi tạo PDF.
